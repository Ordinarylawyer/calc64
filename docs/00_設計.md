# Calc64 設計 ― 計算の考え方

## 1. 目的

本訴・反訴・別訴の併合、独立当事者参加などで当事者が多く、請求が入り組んだ事件で、訴訟費用の負担の裁判（民訴法67条1項）の主文を作るのを助ける。

併合された事件ごとに負担割合を定める方法（「Ａ事件に生じた費用の…を原告１の、…Ｂ事件に生じた費用の…」）では、併合後に生じた当事者共通の費用の負担が定まらず、訴訟費用額確定処分で負担額を算定しにくい。控訴審で原判決の一部だけが変更されるときにも、定まらない部分が残りうる（民訴法67条2項）。そこで、**各当事者について、自分と他の当事者に生じた費用のうち負担すべき割合を定める方法**（司法研修所編『民事判決起案の手引』が推奨する方法）の計算をする。

## 2. 入力を外に出さない

- 静的なページだけで動く（サーバーで動くものはない）。`site/index.html` の CSP で外部との通信を禁止する（`connect-src 'none'` など）。
- 外部の CDN・フォント・アクセス解析、ブラウザの保存領域（localStorage など）・Cookie は使わない。
- 続きをするときは、利用者が JSON ファイルを手元に保存し、読み込む。
- `tests/privacy.mjs` が、CSP と、自前の JS が通信・保存の API を使っていないことを確かめる。

## 3. 負担割合の計算

### 3.1 記号

| 記号 | 意味 |
|---|---|
| n | 当事者の数 |
| x[i][j] | 当事者 i から当事者 j への請求額（訴額） |
| y[i][j] | その認容額（0 ≤ y[i][j] ≤ x[i][j]） |
| D_j | 当事者 j が当事者となっている請求の額の合計 = Σk x[j][k] + Σk x[k][j] |
| z[i][j] | 当事者 i が負担すべき、当事者 j に生じた費用の割合 |

自分に請求することはないので x[i][i] = y[i][i] = 0。

### 3.2 考え方

訴訟費用は敗訴者の負担とし（民訴法61条）、一部敗訴のときは裁判所の裁量で定める（同法64条本文）。ここでは、実務で一般的な、**訴額と勝訴の割合で按分する**方法をとる。

当事者 j に生じた費用は、j が当事者となっている請求の全体（訴額 D_j）について生じたものとみる。そのうち i と j の間の請求に係る部分（訴額 x[i][j] + x[j][i]）は、その請求で i が敗訴した額の割合で i が負担する。

- i が j に負けた額 ＝ j の i に対する請求の認容額 y[j][i] ＋ i の j に対する請求の棄却額 (x[i][j] − y[i][j])

よって i ≠ j のとき

```
z[i][j] = (y[j][i] + x[i][j] − y[i][j]) / (x[i][j] + x[j][i]) × (x[i][j] + x[j][i]) / D_j
        = (y[j][i] + x[i][j] − y[i][j]) / D_j
```

自分の費用については、自分に対する請求の認容額と、自分の請求の棄却額の合計の割合で負担するので

```
z[i][i] = (Σk y[k][i] + Σk x[i][k] − Σk y[i][k]) / D_i
```

各列の合計 Σi z[i][j] は 1（100%）になる（D_j > 0 のとき）。D_j = 0 の当事者（どの請求にも関わらない当事者）の列は計算しない。

`tests/engine.mjs` は、乱数で作った架空の事例について、この式の結果を、請求 1 件ごとに費用を割り付けて足し上げる計算（式に整理する前の考え方そのもの）と突き合わせている。

### 3.3 入力の扱い

- 請求の一覧（請求する当事者・請求される当事者・請求額・認容額）から x・y を作る。同じ当事者間の請求が複数あれば足す（当事者数 × 当事者数の表は、画面の「請求額・認容額の行列」で確かめられる）。
- 請求される当事者を複数選んだ行（連帯請求など）は、請求額・認容額をその人数で等分する。連帯債務者間で便宜的に按分するもの。等分が相当でないときは、相手方ごとに行を分ける。
- 金額は四則演算（`+ - * /`、`× ÷`、括弧）、桁区切り、全角、「円」、「万」「億」（例：`66万8919`）で入れられる。`eval` は使わず、小さな構文解析で計算する。負の額・0 での割り算は誤り。
- 認容額が請求額を上回る行は誤りとして示し、主文例は出さない。

## 4. 平易な分数の提案

厳密な割合は主文には細かすぎるので、列（当事者 j に生じた費用）ごとに、共通の分母 d で近似する分数を提案する。

1. 各当事者の分子は、割合 × d を最も近い整数に丸めたもの（ちょうど半分のときは偶数へ）。
2. 次の条件をすべて満たす d を「使える分母」とする。
   - **分子の合計が d に等しい**（その当事者に生じた費用の全部を割り付ける）。
   - 割合が 0 でない当事者の分数は、厳密な割合との差が、その割合の ±15% 以内。
   - ただし、割合が 0.5% 未満の当事者は 0 にしてよい（民訴法64条ただし書）。
3. 分母 1〜10 の中に使える分母があれば、そのうち**ずれ（各当事者の差の絶対値の合計）が最も小さいもの**（同じなら小さい分母）。分母が小さいうちは、分母が 1 違うことの影響が大きいため。
4. 10 までに無ければ、11〜100 の中で最初に見つかった使える分母。
5. 100 までに無いとき（ごく小さい割合があるときに起こる）は、分母を 100 とし、最大剰余法で分子の合計を 100 にそろえて、その旨を示す。
6. 表示と主文例では約分する（例：2/4 → 1/2）。大小関係は丸めで逆転しない（同じになることはある）。

15%・0.5%・10・100 は「提案の条件」で変えられる。提案した分数は画面で直せる。直した分数は、列ごとに合計が 1 になっているかを有理数で確かめ、1 でなければ主文例を出さない。

## 5. 主文例

### 5.1 原則の形

負担する当事者ごとに、各当事者に生じた費用の割合を並べる。割合が 0 の部分は省く。

> 訴訟費用は、Ａに生じた費用の３分の１、Ｂに生じた費用の３分の１及びＣに生じた費用の３分の１をＡの、Ａに生じた費用の３分の１及びＢに生じた費用の３分の２をＢの、…をＤの負担とする。

- 同じ負担者の中で最後の費用の前は「及び」でつなぐ。「提案の条件」で「、」だけにもできる。
- 分数の数字は全角。全部を負担するときは「全部」。
- 名前を入れていない当事者は「当事者１」などとする。

### 5.2 簡潔な形（使えるときだけ、あわせて示す）

どの当事者に生じた費用も、同じ割合で負担させることになるとき（典型は 2 当事者）は、次の形もあわせて示す。

> 訴訟費用はこれを５分し、その２を原告の負担とし、その余を被告の負担とする。
>
> 訴訟費用は被告の負担とする。

分母は、各負担者の分数の分母の最小公倍数。
